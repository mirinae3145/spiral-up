# Task continuation

Use this procedure to understand a handoff, prepare a restart, or continue handed-off work.
No guidance improvement or observation question is required.

## Reconcile with the current state

Check the actual artifacts and work state before executing the handoff's suggested next step.
For repository work, inspect the current branch, relevant changes and untracked files, and the revisions or diffs needed to understand what changed since the handoff.
Preserve existing work and identify completed, superseded, conflicting, or still-open items.
Inspect external state only when relevant and accessible through authorized tools.

Use earlier validation as evidence within its known revision and environment.
Reuse results when intervening changes cannot affect them; rerun affected checks when the current state makes them stale.
Do not treat missing validation records as either a pass or a failure.

Choose a restart point from the remaining objective, current dependencies, and unresolved decisions rather than mechanically following the recorded order.
When the handoff conflicts with current evidence, explain the difference and adapt within the authorized objective.
Ask when resolving the difference would materially change user intent or require an action outside existing authorization.

## Prepare or continue

For preparation only, provide the recovered objective, current state, material gaps, and a concrete starting point with relevant paths or references.
For execution, briefly explain consequential changes to the recorded plan, then perform the useful remaining work.
Keep ordinary task implementation and validation under the applicable project guidance and task-specific skills.
Guidance improvement and additional follow-ups remain separate objectives unless the user includes them.

If continuation supplies relevant evidence for an open observation question, use [Observation follow-up](observation.md) for the requested assessment or recording.
Do not start a separate investigation merely because a general handoff is being resumed.
